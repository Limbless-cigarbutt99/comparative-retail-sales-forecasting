The software provides two sets of predictions based on different mathematical approaches.

## 📝 Preparing Your Data

For the best results, format your input data correctly. Your file should be in a table format, such as CSV or Excel. Include the following columns:

- Date: The specific day of the sale.
- Store ID: The unique identifier for each store location.
- Sales: The total dollar amount sold on that day.
- Promotions: A note on whether a sale or special event occurred.
- Holidays: A note on whether the store was affected by a public holiday.

If your file lacks these columns, the software may not produce accurate forecasts. Ensure your dates follow a standard format like Year-Month-Day to avoid errors in the processing phase.
